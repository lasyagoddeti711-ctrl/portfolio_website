# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, education, and experience as a developer.

## 🚀 Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling, layouts, animations, and responsiveness
* **JavaScript** – Interactivity and dynamic functionality
* **React.js** – Component-based UI development

## ✨ Features

* Responsive design for desktop and mobile devices
* About Me section
* Skills and technologies section
* Projects showcase
* Education and experience details
* Contact section
* Interactive user interface
* Clean and modern design

## 📂 Project Structure


## 🛠️ Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

Navigate to the project folder:

```bash
cd portfolio
```

### 3. Run the website

Open `index.html` in your browser.

If you are using VS Code, you can also use the **Live Server** extension to run the website locally.
